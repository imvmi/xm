# 临时迁移下载接口

这两个 Python 3 脚本用于 Linux 服务器向新主机传输已准备好的迁移包，
边读取边生成 ZIP64，不在服务器上保存完整 ZIP。媒体和头像不重复压缩。

先正常停止用户级 `xm.service`，将完整迁移目录放在脚本旁的 `app/` 中。
目录应包含程序、配置、数据库、媒体、头像及 `manifest.json`。
SQLite 必须在服务正常关闭后复制；媒体可以在同一文件系统内使用硬链接。
硬链接不是独立备份，传输期间必须保持源服务停止且不修改媒体内容。
脚本不负责创建数据快照或生成校验清单。

通过 SSH 输出 ZIP 到接收方：

```bash
python3 stream-archive.py
```

该命令将二进制 ZIP 写到标准输出，应通过 SSH 重定向到接收方文件，
不要直接在终端运行。也可启动 HTTP 下载接口：

```bash
python3 download-server.py --host 0.0.0.0 --port 3000
```

启动后，随机下载路径写入 `.download-path`，访问密钥保存于
`.download-token`，均仅当前用户可读。将服务器地址与端口放在路径前即可下载。
仅接受特定路径的 GET/HEAD 请求；不提供目录浏览，同时只允许一次下载。
断开连接会停止打包；传输错误不会被标记为完整下载。

HTTP 接口不提供加密，链接持有者可下载全部数据，迁移包可能包含登录和存储凭据。
通过可信网络使用，或在前面配置 HTTPS 代理。下载完成后停止进程。
流式 ZIP 不支持断点续传，断线后需重新下载；同时保留 ZIP 和解压文件需要约两倍空间。

运行时目录、密钥及下载路径已在本目录的 `.gitignore` 中排除。
