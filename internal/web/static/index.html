XM 采集与下载

负责步骤 1、3、4：安排任务、保存推文、下载和归档媒体。

任务调度与媒体下载

以下为全局设置。各表单分别保存；当前任务继续使用启动时的参数。

全局自动采集

切换后立即保存。关闭后暂停所有账号的自动采集，当前任务继续执行，仍可手动采集；开启后按各账号的采集计划运行。

步骤 1 · 任务调度

默认周期用于跟随全局的账号；账号也可单独设置周期。修改默认周期只重新安排跟随全局的账号；账号间隔设为 0 时，上一任务结束后立即开始下一任务。

网络与限流

控制 XM 发出的网络请求，以及遇到 X 限流后的暂停时间。

X 返回限流后才开始冷却。实际等待还受自动采集周期、连续限流次数及 X 指定时间影响；手动任务也需要等待。

限流与恢复

手动清除 XM 收到 429 后设置的采集冷却，立即生效。任务仍按启用和暂停设置运行，归档数据、分页断点和排队任务会保留。此操作不能解除 X 服务器端的限制，仍可能再次收到 429。

步骤 4 · 媒体下载与重试

每页入库后，XM 在后台逐个下载图片和视频，Chrome 同时继续读取推文。下载与采集共用网络和任务时限；下载失败不影响已保存的推文。

支持续传的媒体会分段下载，网络中断后保留断点，下次重试继续；重启 XM 后仍可恢复。链接变化或服务器无法可靠续传时，自动从头下载。

临时失败会逐次延长等待时间，到期后在后续采集任务中重试。永久格式、域名或大小错误不会自动重试；S3 单文件上传上限仍为 5 GiB。

媒体重试

清除所有账号临时下载失败后的剩余等待，立即生效，无需保存设置。清除后请手动更新对应账号，或等待后续自动采集；不会立即开始下载。重试间隔配置、失败次数和错误记录保留，永久失败的媒体不受影响。请在采集批次结束后操作。

本地下载暂存

未完成下载默认最多占用 2 GiB；单文件上限超过此值时，会自动提高到可容纳一个文件。空间不足时暂停新增下载，保留已有进度。即使使用远端存储，也需要本地暂存。

清理只删除尚未下载完整的断点，之后需从头下载。已归档媒体和已下载完整的待上传文件保留；待上传文件完成上传并校验后会自动释放。请在采集批次结束后清理。

Chrome 浏览器

负责步骤 2：连接浏览器、读取 X 页面；下方同时管理整个账号任务的时限。

连接 Chrome

选择本地启动 Chrome 或通过 CDP 连接已有浏览器。

填写 XM 服务器可访问的 Chrome 调试地址和端口（支持 IPv4、IPv6 和 localhost），该端口需提供 /json/version 接口。BrowserBox 等服务的管理页面端口不等于 Chrome 调试端口。

CDP 模式使用独立会话，结束时保留远端浏览器及其已有页面。浏览器代理和 Headless 模式由远端配置；XM 的代理设置继续用于媒体下载等请求。

在 XM 所在服务器启动 Chrome，使用“XM 采集与下载”中的代理和本卡片的 Headless 设置。

默认开启 Headless（无界面）。切换后自动保存，下次诊断和采集生效，当前任务继续使用原模式。关闭后将在运行 XM 的电脑上显示 Chrome 窗口，需要可用的桌面环境；调试完成后建议重新开启。

测试使用上方当前选择的浏览器模式、IP 和端口，无需先保存，也不会修改已保存的配置。「测试连接」仅验证 Chrome 是否可用；下方诊断还会使用已保存的 Cookie 打开 X。代理和 Headless 使用已保存的设置。主页面就绪后验证登录，不等待图片等资源全部加载，也不会读取或保存推文。

页面读取与任务时限

控制步骤 2 的读取节奏，以及整个任务运行多久、何时更换采集会话。

步骤 2 · 页面滚动与停止条件

上一轮页面请求完成后，随机等待 15～25 秒再滚动。

页面到底且没有新内容后，再等待指定秒数结束采集。已保存推文的停止阈值仅用于增量采集，补采历史和重新扫描不受此项限制。

了解时间线结束条件

页面在底部、没有进行中的时间线请求，且推文数量和页面高度均不再变化时开始计时；新响应或页面进展会重新计时。时间线结束、达到已保存边界、遇到限流或任务时限用完，都会结束本轮处理。

任务时限与浏览器复用

两种连接方式均生效。每个账号任务从开始时单独计时，采集和媒体下载共用此时限。超时结束本轮，保留已保存内容和进度。

小时数也用于限制采集会话的复用时间，从会话建立时计时。达到时长或任务数上限后，在下次采集前更换会话；不会因此中断当前任务，空闲时也不会定时关闭。

本地启动：更换会话时，重启由 XM 启动的 Chrome。
CDP 连接：更换会话时，重新连接并创建新的独立采集环境；不重启或关闭远端 Chrome，也不影响其他标签页。

任务时限与会话时间怎样计算？

例如设置为 6 小时：会话已经使用 5 小时后开始新任务，该任务仍有完整的 6 小时时限。任务超时后，未完成内容等待下次自动采集或手动继续，不会仅因超时立即重试。
